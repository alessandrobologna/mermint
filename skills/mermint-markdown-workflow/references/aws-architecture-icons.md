# AWS Architecture Icons

Use this reference when generating Mermaid `architecture-beta` diagrams with the built-in `aws` icon pack.

Rules:

- Prefer concrete AWS service icons over generic Mermaid shapes when the service is known.
- Prefer `aws:simple-storage-service` for S3-style storage instead of `disk`.
- Prefer `aws:dynamodb` for DynamoDB-style state instead of `database`.
- Prefer the shortest stable alias when one exists, for example `aws:dynamodb`, `aws:simple-storage-service`, `aws:simple-queue-service`, `aws:aws-lambda`, `aws:aws-api-gateway`.
- If you are unsure which icon to use, search this file for the AWS product name before falling back to a generic shape.
